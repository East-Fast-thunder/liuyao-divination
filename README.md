# 六爻卜卦 · 铜钱起卦排盘（只排盘，不解卦）

一个纯 Python 标准库实现、无第三方依赖的六爻程序。按传统规则完成：

**起卦 → 四象六爻 → 动爻变卦 → 干支排盘 → 断卦要素陈列**

> 本程序**只做排盘、不做解卦**：不输出卦辞解读，也不下吉凶结论，只把传统六爻的判断框架完整、系统地列出来，供你自行参考。

---

## 快速开始

```bash
# 交互模式（推荐）：填问事 → 起卦 → 排盘 → 自动存档
python main.py

# 演示模式：固定问事、时间与随机种子，结果可复现
python main.py --demo

# 只看历史占卜记录
python main.py --history

# 指定存档目录 / 本次不存档
python main.py --save-dir "D:\我的记录"
python main.py --no-save

# 运行自测（675 项断言）
python tests/test_all.py
```

环境要求：Python 3.8+，无需安装任何依赖。

## 一、起卦层：把随机数变成「四象六爻」

单纯生成 0/1 只能得到**静爻**，连动爻都没有。完整起卦需要得到四象：

| 铜钱组合 | 计算 | 爻值 | 四象 | 阴阳 | 动否 | 变后 |
|---|---|---|---|---|---|---|
| 三正 | 3+3+3 | **9** | 老阳 ○ | 阳 | 动 | 变阴 |
| 两正一反 | 3+3+2 | **8** | 少阴 | 阴 | 静 | — |
| 一正两反 | 3+2+2 | **7** | 少阳 | 阳 | 静 | — |
| 三反 | 2+2+2 | **6** | 老阴 ✕ | 阴 | 动 | 变阳 |

- **概率**：老阴:少阳:少阴:老阳 = 1:3:3:1（各占 1/8、3/8、3/8、1/8）
- **顺序**：**自下而上**掷六次，第 1 掷 = 初爻（最下），第 6 掷 = 上爻（最上）
- **动爻规则**：9（老阳）与 6（老阴）为动爻
- **变卦规则**：动爻取反（老阳→阴、老阴→阳），静爻不变

随机源支持三种：

| 方式 | 说明 |
|---|---|
| 真随机 | `secrets` 加密级随机，不可复现 |
| 可复现种子 | 指定整数种子，同种子出同卦（便于核对/演示） |
| 手工指定 | 直接输入 6 个 6/7/8/9，模拟手工摇卦结果 |

## 二、排盘层：起卦时间与固定排盘表

### 1. 起卦时间 → 干支

- **年柱**：以**立春**为界（非公历元旦，非农历正月初一）
- **月柱**：以**节气**为界（立春起寅月、惊蛰起卯月……小寒起丑月），五虎遁起月干
- **日柱**：1900-01-01 为甲戌日的锚点连续推算，23:00 后子初换日
- **时柱**：两小时一辰，五鼠遁起时干
- **旬空**：按日柱所在旬确定空亡二支
- **月建 / 日建**：月柱地支、日柱地支
- **真太阳时**（可选）：按经度差 + 均时差修正后再排盘

节气用天文近似算法（太阳视黄经，误差约分钟级），不依赖任何外部历法库。

### 2. 八宫卦序与世应

以**京房八宫**排列，每宫八卦：八纯 → 一世 → 二世 → 三世 → 四世 → 五世 → 游魂 → 归魂。

| 世位 | 八纯 | 一世 | 二世 | 三世 | 四世 | 五世 | 游魂 | 归魂 |
|---|---|---|---|---|---|---|---|---|
| 世爻 | 上爻 | 初爻 | 二爻 | 三爻 | 四爻 | 五爻 | 四爻 | 三爻 |
| 应爻 | 与世爻隔二位相冲的正对面爻位 | | | | | | | |

### 3. 纳甲

采用**京房纳甲法**，内卦取内三爻纳甲、外卦取外三爻纳甲。例如：

- 乾：甲子、甲寅、甲辰、壬午、壬申、壬戌
- 坤：乙未、乙巳、乙卯、癸丑、癸亥、癸酉
- 天水讼：甲子、甲寅、甲辰、戊申、戊戌、戊子

### 4. 六亲

以**卦宫五行**为「我」：

| 关系 | 六亲 |
|---|---|
| 生我者 | 父母 |
| 我生者 | 子孙 |
| 同我者 | 兄弟 |
| 我克者 | 妻财 |
| 克我者 | 官鬼 |

### 5. 六神

按**日干**起：甲己起青龙、乙庚起朱雀、丙辛起勾陈、丁壬起腾蛇、戊癸起玄武，
**自初爻往上顺排**（初→上）。

### 6. 伏神

本卦六亲不全时，从**本宫八纯卦**（首卦）中找出所缺六亲所在爻，
作为**伏神**伏于该爻位之下，同时记下**飞神**（本卦该爻的六亲与干支）。

## 三、断卦层：只陈列规则，不作吉凶论断

程序会把以下判断要素系统列出，但**不给结论**：

- **取用神**：按问题类别给出用神优先级（如事业→官鬼→父母→世爻）
- **世应关系**：世代表自己/主体，应代表对方/环境；含生克、冲合
- **旺衰**：用神、世爻在月建日建下的**旺相休囚死**与综合评级
- **生克冲合刑害**：五行生克、六冲、六合、三合/半合、刑害
- **动变关系**：回头生、回头克、化泄、化耗、化进神、化退神、化冲、化合
- **特殊状态**：空亡、月破、日冲、入墓、绝、伏神飞神
- **六神辅助**：青龙/朱雀/勾陈/腾蛇/白虎/玄武的辅助性质（非主判）
- **三合局**：卦中六爻连同月建、日建检查三合与半合

> **应期未实现**：传统应期推法争议大、准确率有限，本程序不做。

## 四、问卦信息层

六爻极依赖「所问之事」是否明确，交互模式会收集：

- 具体问题
- 问题类别（用于取用神）
- 与对方的关系定位
- 事情背景与时间范围
- 问自己 / 问双方关系 / 代问别人
- 是否有明确时限

**适合度检查**：若问题宿命化（如「死之前能否在一起」「是不是没救了」），
程序会提示改写为可操作问法，例如：

> 「我和对方目前关系的主要阻力是什么，我能做哪些改善？」

## 六、存档层：每次占卜结果自动存文件

每次占卜完成后，结果会自动保存到 **`占卜记录/`** 目录（可用 `--save-dir` 改），
一次占卜生成 **两个文件 + 一份索引**：

| 文件 | 内容 | 用途 |
|---|---|---|
| `20261027-120000-晋卦.txt` | 完整排盘报告（与屏幕输出一致） | 直接阅读、打印、分享 |
| `20261027-120000-晋卦.json` | 结构化记录 | 复现、检索、统计、二次开发 |
| `index.md` | 全部记录总目录（表格） | 一眼总览历史占卜 |

**文件名规则**：`起卦时间戳-本卦名`，天然按时间排序；同一秒重名时自动追加 `-2`、`-3`，
**绝不覆盖旧记录**。

**JSON 记录包含**：问事信息、起卦时间与干支四柱、月建日建旬空节气、起卦过程（每爻
铜钱结果与四象、随机源与种子）、卦象（本卦/变卦/卦宫/世应/六爻干支五行六亲六神/空亡
月破/动爻变爻/伏神）、取用神。

> 因为记录了**随机种子**，`起卦(seed=种子)` 可完整复现同一卦，便于事后核对。

命令行操作：

```bash
python main.py --history              # 查看历史记录
python main.py --save-dir "D:\记录"   # 指定存档目录
python main.py --no-save              # 本次不存档
```

存档失败（如磁盘只读）只会打印提示，**不影响本次占卜的显示结果**。

## 八、作为库调用

```python
from datetime import datetime
from liuyao import (
    构建干支时间, 起卦, 排盘, 取用神, 输出排盘, 问事,
    保存记录, 列出记录, 读记录,
)

时间 = 构建干支时间(datetime.now())          # 可传 tz_hours / longitude
结果 = 起卦(seed=None)                        # None=真随机；给整数可复现
盘   = 排盘(结果, 时间)
问   = 问事(问题="未来三个月项目发展", 类别="事业工作")

print(输出排盘(盘, 问.转为字典(), 取用神("事业工作")))

paths = 保存记录(盘, 问, 取用神("事业工作"))   # 存档，返回 txt/json 路径
print(paths["文本"], paths["JSON"])

for r in 列出记录():                          # 列出历史
    print(r["公历"], r["本卦"], r["问题"])
data = 读记录("20261027-120000-晋卦.json")    # 读回单条
```

`起卦(手动输入=[7,8,9,6,7,8])` 可直接指定六爻（从下往上）。

## 九、已知取舍

- **节气精度**：天文近似算法误差约分钟级；若起卦时刻恰好卡在节气交接几分钟内，可人工微调时间。
- **六冲卦/六合卦**：取通行的 10 个六冲卦与 8 个六合卦名单，各家流派略有差异。
- **十二长生**：土随水行（土长生在申、逆行）。
- **不作解卦**：本程序不输出卦辞、爻辞与吉凶判断，这是设计上的明确取舍。
- **存档不加密**：记录为明文 UTF-8/JSON，便于自己查看，涉及隐私请自行保管 `占卜记录/` 目录。
